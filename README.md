# 麻将AI - 免费麻将牌识别与出牌建议

## 功能
- 拍照 / 选图识别麻将牌（YOLO11n 检测模型，32 类，含红中）
- 红中作为万能牌，不主动打出
- 向听数算法（-1=胡牌，0=听牌，N=N向听）
- 出牌建议：模拟打出后向听数最低的牌
- 悬浮窗显示：识别结果悬浮在游戏上层，可拖动，可关闭
- 手牌 13/14 张自动校验

## 云构建（GitHub Actions）
1. 把整个文件夹推送到 GitHub 新仓库
2. Actions 自动运行，构建完成后在 Actions 页面下载 `mahjong-ai-debug` 产物
3. 得到 `app-debug.apk`，直接安装到手机

## 使用流程
1. 打开应用，点「开启悬浮窗」并授予悬浮窗权限
2. 点「拍照识别」对着牌面拍照（手牌在屏幕下方）
3. 识别结果显示在页面和悬浮窗中
4. 切到游戏 App，悬浮窗会一直显示建议

## 本地构建
- Android Studio 打开项目，直接 Run

## 模型
- `app/src/main/assets/best.onnx`：YOLO11n，640x640 输入，32 类麻将牌
- 类别顺序：条1-9、万1-9、筒1-9、东南西北红中
- 红中 class id = 29（万能牌）

## 注意
- 识别效果取决于模型训练质量与拍照角度/清晰度
- 建议正对牌面、光线充足、背景干净
