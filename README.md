# 麻将AI - 屏幕识别麻将牌与出牌建议

## 功能
- **屏幕识别**：MediaProjection 截屏，实时识别屏幕上的麻将牌（适合玩游戏时用）
- 拍照 / 选图识别（备选）
- 红中作为万能牌，不主动打出
- 向听数算法（-1=胡牌，0=听牌，N=N向听）
- 出牌建议：模拟打出后向听数最低的牌
- 悬浮窗显示：识别结果悬浮在游戏上层，可拖动，可关闭

## 云构建（GitHub Actions）
1. 把整个文件夹推送到 GitHub 新仓库
2. Actions 自动运行，构建完成后下载 `mahjong-ai-debug` 产物
3. 得到 `app-debug.apk`，直接安装

## 使用流程（屏幕识别）
1. 打开应用，点「开启屏幕识别」
2. 首次会依次弹出：悬浮窗权限、屏幕捕获授权，都允许
3. 切到麻将游戏，悬浮窗每 2 秒自动截屏识别并更新建议
4. 点悬浮窗 ✕ 或回到应用点「关闭屏幕识别」停止

## 本地构建
- Android Studio 打开项目，直接 Run

## 模型
- `app/src/main/assets/best.onnx`：YOLO11n，640x640 输入，32 类麻将牌
- 类别顺序：条1-9、万1-9、筒1-9、东南西北红中
- 红中 class id = 29（万能牌）

## 注意
- 识别效果取决于模型质量、屏幕分辨率与游戏牌面大小
- 手牌默认按屏幕下方筛选（y>62%），如游戏布局不同可改代码
